### NASA Airfoil Self-Noise Prediction

![Python](https://img.shields.io/badge/Python%203-3776AB?style=flat-square&logo=python&logoColor=white)
![Scikit--Learn](https://img.shields.io/badge/Scikit--Learn-F7931E?style=flat-square&logo=scikit-learn)
![Pandas](https://img.shields.io/badge/Pandas-150458?style=flat-square&logo=pandas&logoColor=white)

Regression model for aerodynamic noise on the NASA airfoil dataset. Random
Forest inside a scikit-learn `Pipeline` (no leakage across the train/test split),
tuned with `GridSearchCV` and cross-validation — MAE 1.33 dB, RMSE 1.84 dB.

[Repository](https://github.com/lucasschn1/previsao-ruido-aerodinamico-nasa)
